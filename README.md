# The Hate Circuit

## Python application using Pygame Zero to display images based on sentiment analysis from Facebook posts.

Posts are polled from Facebook using the `socialapis` library and then cleaned using the `unidecode` library. The sentiment analysis is created using the `textblob` library. Images are displayed dependent on the average of sentiments for posts retrieved. If posts are deemed "positive" then a relay is activated that switches on an air compressor to inflate an attached rubber dingy.
